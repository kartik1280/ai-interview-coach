# AI Interview Coach — Frontend

Retro 1980s Macintosh-inspired landing page built with React, Vite, Tailwind CSS, and Framer Motion.

## Getting Started

```bash
npm install
npm run dev
```

The app will be running at `http://localhost:5173`.

## Features
- Pinned Sticky CRT Monitor on scroll (`position: sticky`)
- Scroll sequence copy reveal inside phosphor green screen
- Interactive purple 3.5-inch floppy disk with shutter panel action buttons
- Smooth disk insertion animation targeting drive slot
- CRT Screen form swap for user authentication (Sign Up / Log In)
